    怎么玩

    1. 井口掉下来一个真实的风险，下面那句是它的情境，先读它。
    2. 你手上三张卡，每张是原书的一条建议。牌面不标分类，只标成本（钱 / 时间 / 毅力）和证据等级。
    3. 挑出真正能接住这个风险的那一条。三条里只有一条是原书明确指向它的，另外两条讲的是别的事。
    4. 每个风险只有一次机会。点错了，方块直接砸下去堆一层，进下一个风险。
    5. 不管选对选错，都会弹一张讲解卡，把原书那条建议的「说人话 / 收益 / 证据 / 来源」讲完。 读完点「继续」，下一手才开始。
    6. 撑满 19 手、井没堆满 10 层，这辈子就算圆满。
    7. 钱和时间基本不缺，毅力才是真稀缺的。出牌之前先看成本。

    净值是你这一生的账。活过一手、接住一个风险、接得漂亮，都会一笔一笔记上去。 满分 1008。
    每一手都会加分：活过 +8，接住风险 +16，再按证据等级（A +8 / B +5 / C +2）、 出手从容程度（方块还在上半段 +8 / 中段 +4 / 最后关头 +1）、 连击（每多连一手 +2，封顶 +10）往上叠。漏一次，连击归零。
    出牌：点卡片，或按 1 2 3。放过：空格。 暂停：P。
    看详情：长按卡片（电脑上是把鼠标停在卡片上），进去以后 左右滑动或按 ← → 换牌，Esc 或点空白处退出。
